# 🚀 AI Autonomous System

This is an advanced self-learning AI system that can upgrade itself, fix errors, and process commands through an inbox system.

## Features:
- **Self-Build:** Automatically scans and installs new AI technologies.
- **Error Fix:** Detects and fixes errors in the system.
- **Command Center:** Processes commands sent via the inbox.
- **Advanced AI:** Self-evolves by integrating with external AI systems like GPT.

## How to Use:
1. Run `deploy.py` to start the AI system.
2. Send commands to the system via the `/send-command` API endpoint.
3. The system will automatically upgrade, fix errors, and evolve.

## API Endpoints:
- **Send Command:** `POST /send-command`
- **Get Commands:** `GET /get-commands`
